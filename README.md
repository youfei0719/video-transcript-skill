# Video Transcript

一个用于 Codex 的视频稿件提取与核对 Skill。它只做一件事：取得真实语音稿，做有证据约束的二次核对，并输出便于阅读的完整自然段文稿。

它优先使用用户提供的字幕或原稿，其次使用当前 Codex 会话已有的媒体理解能力，最后调用已经配置且获用户批准的转写 MCP 工具。随后依据音频、字幕、可见字幕/OCR、时间戳和上下文修复有证据支持的语义识别错误、同音词与错别字，输出按语义顺序整理的完整自然段稿件。

## 功能

- 支持本地视频/音频、用户提供的字幕/原稿，以及有权访问的平台链接
- 不安装本地模型、转写运行时、媒体处理工具或平台抓取软件
- 字幕优先；没有字幕时使用当前会话已有的媒体能力，或已配置的远程转写 MCP 工具
- 平台链接只通过已有的授权连接器或浏览器能力获取字幕/临时媒体引用，不绕过登录、反自动化或访问控制
- 保留未修改的 `raw` 原始稿件
- 输出 `reviewed` 语义复核稿，保留原始顺序，不摘要、不创作、不改写观点
- 记录可审计的修订原因、证据和置信度
- 临时视频、音频、浏览器配置和 Cookie 在处理完成后清理，不进入项目文件

## 在 Codex 中使用

安装到 `~/.codex/skills/video-transcript` 后，在对话中调用：

```text
$video-transcript
```

然后粘贴视频链接，或提供本地媒体/字幕文件。Skill 会先检查当前会话是否存在真正的字幕或转写消费者，再决定是否获取媒体；不会先下载一个无法转写的视频。它会返回来源、原始稿件、完整复核稿、修订记录和核验状态。Skill 不会要求使用者安装本地转写软件；如果当前会话没有媒体理解能力，且没有字幕或已配置并获批准的转写工具，会返回可恢复的 `blocked` 结果，说明固定错误码、保留来源并给出下一步输入，而不是伪造稿件或让用户重复粘贴链接。

## 转写工具契约

要把“平台链接到文稿”闭环做成零本地安装体验，需要一个已部署的远程 MCP 转写工具。该工具由服务端处理临时媒体和 ASR，客户端不下载模型；必须在请求结束时删除媒体/音频，并返回未改动原稿、时间戳、置信度和保留状态。详细输入输出与隐私要求见 [transcript-tool-contract.md](references/transcript-tool-contract.md)。

Skill 本身不内置抓取器或 ASR 服务，不会因为安装它而静默向第三方发送媒体。用户必须在每次使用远程工具前明确批准该来源的传输。失败不是终点：补充 `.srt`、`.vtt`、`.txt`、本地音视频，或批准已配置的转写工具后，Skill 从上次完成的阶段继续。

## 输出层次

| 文件 | 作用 |
| --- | --- |
| 默认聊天输出 | 完整的自然分段复核稿，以及必要时的待确认片段 |
| `manuscript.raw.md` | 仅在用户要求保存审计文本时写入的未修改 ASR/字幕原文 |
| `manuscript.reviewed.md` | 仅在用户要求保存审计文本时写入的完整复核稿 |
| `corrections.json` / `verification.json` | 仅在用户要求保存审计文本时写入的证据、修订和未决问题 |

## 约束

本项目不绕过登录、反自动化、付费墙、地区限制或版权控制；标题、描述和分享文案不能替代实际视频内容。不会隐式安装软件、下载模型权重，也不会将媒体静默发送到第三方服务。无法由来源证据确认的文字会保留为未决项，不会凭上下文臆造。
