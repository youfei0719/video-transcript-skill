# Video Transcript

一个用于 Codex 的视频稿件提取与核对 Skill。它只做一件事：取得真实语音稿，按上下文进行二次核对，修复有依据的语义识别错误和错别字，并输出按语义顺序分好的完整自然段文稿。

## 功能

- 接受视频链接、本地视频或音频、字幕文件，或用户提供的原稿
- 优先使用当前 Codex 会话已经具备的媒体、字幕或转写能力
- 不要求安装本地模型、BaoCut 或其他厂商软件
- 不把标题、描述、话题、缩略图、分享文案或 OCR 文字当作口述稿
- 保留原始说话顺序和有意义的重复，不摘要、不创作、不改写观点
- 根据音视频、源字幕和上下文修复可确认的同音词、专名、数字、否定词、漏字、重复和错别字

## 在 Codex 中使用

安装到 `~/.codex/skills/video-transcript` 后，在对话中调用：

```text
$video-transcript
```

然后粘贴视频链接，或提供本地媒体、字幕和原稿。默认先返回完整的自然分段复核稿；只有在需要审计时才展开原始稿和逐项修订。

如果当前会话无法取得真实语音内容，Skill 会明确说明缺少的证据，并请求 `.srt`、`.vtt`、文本原稿或可读取的音视频文件，不会根据分享文案猜写稿件。
