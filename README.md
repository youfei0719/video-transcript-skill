# Video Transcript

一个用于 Codex 的视频稿件提取与核对 Skill，优先使用 Codex 当前会话已有的原生媒体理解能力。

它的目标很窄：从用户提供且有权访问的视频来源获取真实语音内容，生成原始 ASR 稿件，再依据音频、字幕、可见字幕/OCR 和上下文修复有证据支持的语义识别错误、同音词与错别字，输出按语义顺序整理的完整自然段稿件。

## 功能

- 支持本地视频/音频、用户提供的字幕或公开抖音分享链接
- 不要求安装 BaoCut、Whisper、本地模型或其他 ASR 软件
- 公开抖音链接优先使用匿名 Chromium 公开页面解析，不读取用户浏览器 Cookie，不要求登录；下载后的临时媒体交给当前 Codex 会话可用的原生媒体能力处理
- 保留未修改的 `raw` 原始稿件
- 输出 `reviewed` 语义复核稿，保留原始顺序，不摘要、不创作、不改写观点
- 记录可审计的修订原因、证据和置信度
- 临时视频、音频、浏览器配置和 Cookie 在处理完成后清理，不进入项目文件

## 在 Codex 中使用

安装到 `~/.codex/skills/video-transcript` 后，在对话中调用：

```text
$video-transcript
```

然后粘贴视频链接，或提供本地媒体/字幕文件。Skill 会返回来源、原始稿件、完整复核稿、修订记录和核验状态。Skill 不会要求使用者安装本地转写软件；如果当前 Codex 会话无法读取媒体且没有字幕或用户批准的外部转写服务，会明确返回 `blocked`，而不是让用户配置一套额外环境。

## 输出层次

| 文件 | 作用 |
| --- | --- |
| `manuscript.raw.md` | 未修改的 ASR/字幕原文 |
| `manuscript.reviewed.md` | 语义复核、错字修复、自然分段后的完整稿件 |
| `corrections.json` / `verification.json` | 证据、修订和未决问题 |

## 约束

本项目不绕过登录、反爬、付费墙、地区限制或版权控制；标题、描述和分享文案不能替代实际视频内容。不会隐式安装 BaoCut、Whisper 或下载模型权重，也不会将媒体静默发送到第三方服务。无法由来源证据确认的文字会保留为未决项，不会凭上下文臆造。
